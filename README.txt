# 🟢 GFG Quiz Arena

### Learn. Think. Win.

GFG Quiz Arena is an online quiz platform where students can participate in quizzes, test their knowledge, and view their results. The platform also provides an owner dashboard to create quizzes, manage questions, and review student performance.

## 🌐 Live Website

🔗 https://gfg-quiz-arena.vercel.app

## ✨ Features

- 🎯 Interactive online quizzes
- 👨‍🎓 Student registration with name, department, and year
- ⏱️ Custom timer for each question
- 📝 Multiple-choice questions with configurable options
- 🔐 Secure owner authentication
- 📚 Create and manage quizzes
- 📊 View student quiz results
- 📱 Responsive user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- Vercel
